# Vault — StealthO's Compounding Memory

This is the brain. Every idea, every factory run, every lesson learned, every bet made — it all lives here. Read first. Write back. Never start from zero.

## Structure

```
vault/
├── README.md            ← You are here
├── ideas/               # Every idea Kendall throws out
│   └── {idea-name}.md   # One file per idea — validation, brand, spec, lifecycle
├── cycles/              # Every factory run, timestamped
│   └── YYYY-MM-DD_{idea-name}.md  # Full log: verdict → build → deploy → learnings
├── learnings/           # What worked, what didn't — folded back into the boilerplate
│   └── {pattern}.md     # One pattern per file
├── bets/                # Trend bets — early calls on where the market is going
│   └── {bet-name}.md    # Bet: what, when, why. Outcome: logged and learned from.
└── metrics/             # North star metrics per product
    └── {product-name}.md # Sign-ups, revenue, retention — real data only
```

## Rules

1. **Read the vault first.** Every session starts here. Check what's already been tried.
2. **Write back everything.** Every factory run, every decision, every failure.
3. **Compound.** If a lesson repeats, it becomes a directive. If a pattern works, it becomes part of the boilerplate.
4. **Truth only.** No fake metrics, no inflated numbers. Real data or nothing.
5. **Link everything.** Every PR, every deployment, every bet — link back to its vault entry.
