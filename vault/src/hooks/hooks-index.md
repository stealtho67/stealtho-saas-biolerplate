# Hooks Directory — `src/hooks/`

| Hook | Purpose |
|------|---------|
| `use-mobile.jsx` | Detects mobile viewport — returns `isMobile` boolean |
| `useDarkMode.js` | Dark mode toggle — persists preference to localStorage |
| `useMediaQuery.js` | Generic media query hook — returns match state |
| `usePullToRefresh.js` | Mobile pull-to-refresh gesture handler |
| `useScrollReveal.js` | Scroll-triggered fade-in animation hook |
